- **Таблиця 1.1, рядок «Бюджетні …»** — варіанти: Бюджетні наукової установи, підприємства, організації НААН, усього (Pass 1, Pass 2) | Бюджетні наукові установи, підприємства, організації НААН, усього (Pass 3).
