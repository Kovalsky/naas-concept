# Source documents — НААН (archive for review)

The **original images** the stakeholder provided, each paired with an **MD file** containing the text extracted from it. Open an image next to its `.md`, and **edit the `.md` if anything is wrong** — these are the inputs that drive `../source-of-truth-naas.md` (consolidated facts) and the site content.

**How extraction was done:** each printed/handwritten image was transcribed by 2–3 independent OCR passes, then a reconciler re-read the image and flagged disagreements. Confidence: **HIGH** = clean print, fully legible · **MEDIUM** = mostly clear, a few flagged items · **LOW** = needs confirmation. Uncertain tokens are marked `⟨?⟩`; each file ends with a «Потребує уточнення» list.
